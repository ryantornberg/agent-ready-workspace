# Agent contract

- For a bug that is small, easy to reverse and in one repository, follow `docs/playbooks/fix-a-bug.md`.
- Work is done when it meets `docs/definition-of-done.md`. End with the report it describes.
- Mark every claim in the report as verified or inferred.
- Stage files by name. Never `git add -A`, `git add .` or `git commit -a`: another session may have edits in this folder.
