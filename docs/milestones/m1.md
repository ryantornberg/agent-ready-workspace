What the checks and the red team caught in slice 0:

- **The session locked itself out.** A change to the `deny_list` part made two of its old cases fail before the cases file was updated. Every hook call loads every part, so every shell and edit call was then refused, including the repair. The maintainer repaired it from their own terminal. This is the self-lock that slice 2 removes.
- **A part was skipped without a word.** The commit check did not run `deny_list` while the manifest that adds it was unstaged, because the staged manifest decides. Slice 2's required-parts rule covers this.
- **A unit test's sample terms matched text in the part's own cases file.** The test now uses different terms.
- **The red team found ten problems in slice 0 and this plan.** All are triaged in the plan's [red team](../plans/m1-make-the-core-hold-weight.md#red-team) table.
