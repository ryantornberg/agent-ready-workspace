# Red team review: docs/plans/m4-fail-closed-guards-review-loop-and-evals.md

A twenty-first fresh red team's attack on M4's draft hand-off plan, checking the claims its decisions rest on against the repository.

**In short:** holds with fixes, 5 findings. The fast path's 5 minutes rests on the fastest of 17 Linux runs; the median is 7. Q110 still misses two pages that say where a page commit goes.

The red team read the plan, the red team review page, the round 20 record, and the sources the plan names, at the commit above, with a clean tree. It read the diff of the plan since round 20's commit, `cc63ed0`. It read `.github/workflows/ci.yml` and `cold-clone.yml`, `workspace.json`'s `direct_push` and `review_trailer` entries, `kit/kit.json`, `docs/procedure-endings.md`, `docs/extend-the-workspace.md`, `docs/changing-the-machinery.md`, `docs/decisions/0011-pages-go-straight-to-main.md`, `docs/decisions/0004-the-hook-contract.md`, `parts/no_discard.py`, `.githooks/pre-commit` and `wslib/runner.py`'s commit snapshot. It ran `gh run view --json jobs` on the 17 most recent completed CI runs, read main's required status checks with `gh api`, listed the tracked `.md` files outside `docs/`, and traced the review-session row through the plan's history with `git show`.

## Verdict

**Holds with fixes.** Round 20's fixes landed. The Linux job now runs every test and hook case, which ends three rounds of trouble picking page-reading tests. Wrappers and case files qualify for the fast path, since `plugin/` is not machinery. Decision 0011 and procedure endings' "Off main" section are named. The guards, the harness, the eval budgets and the review loop are unchanged and still add up. Two things do not yet hold. Criterion 65's 5 minutes is the fastest of 17 Linux runs, and the median is about 7, before M4 adds its own tests (finding 1). And the commit-time refusal R20-5 added makes two pages that still send a page commit to main lead straight into it (finding 2). Both are fixable inside H2.

## What survives

- **Linux running everything closes R20-2 and R20-3.** Every unit test and hook case runs on the pull request, on the one Ubuntu job, so no test has to be picked by name and no hook rows by part. Verified, by `ci.yml`'s matrix: one Ubuntu job, at 3.13, among five required jobs.
- **The other jobs' kept steps are cheap.** On every job, the selftest, `grade.py --recorded`, the history scan, the commit checks and `ws.py check --phase ci` each took 7 seconds or less. Setup on 3.9 adds about 30 seconds. Verified, by `gh run view 46104249965 --json jobs`.
- **Wrappers and selection cases qualify for the fast path.** `plugin/` is not on `direct_push`'s machinery list, and every tracked file under `plugin/` but `plugin.json` is a `.md` file, the case graders included. `kit/`, `tests/` and `.github/` are on the list, so `kit/seed/README.md` and `.github/copilot-instructions.md` still take the full run. Verified, by `workspace.json` and `git ls-files`.
- **R20-1's fix is right where it reaches.** Decision 0011 says "Two exceptions", and its last bullet repeats the off-main rule. A third exception and an "Off main" exception for a wrapped page's branch fit both. Verified, by reading the decision and procedure endings.
- **R20-4's rule is consistent.** "Limits" keeps every workflow change for a person, `prose` until L3's refusal is on main. "The maintainer's steps" names L3's and H2's workflow changes. The classing paragraph points at "Limits". Verified, by reading the three places.
- **The suite mark's weakness is named, not hidden.** CI runs no agent, so nothing CI can read would back a suite mark that a script could not also write. Naming the gap in the non-goal and the README is the honest fix. Inferred, from the non-goals "No live agent run in CI" and "No guard on what an interpreter or a script does".
- **The eval budget arithmetic is unchanged and right.** 135 + 400 + 660 + 45 + 45 + 45 is 1,330. With re-records, 180 + 400 + 660 + 45 + 90 + 90 is 1,465. The upkeep row's 12 runs for `search-every-source` is four cases at three runs each. Verified, by adding the rows and listing `plugin/evals`.
- **The record-only set has one definition.** "First real use", "Only the runner writes a mark" and L3's record-only paragraph all use the store's path patterns. Verified, by reading the diff since `cc63ed0`.
