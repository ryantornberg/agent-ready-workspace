# Red team review: docs/plans/m4-fail-closed-guards-review-loop-and-evals.md

A twentieth fresh red team's attack on M4's draft hand-off plan, checking the claims its decisions rest on against the repository.

**In short:** holds with fixes, 8 findings. Q110 still misses decision 0011 and procedure endings' off-main rule. The fast path's test marker scan misses tests that read pages through helpers.

The red team read the plan, the red team review page, the round 19 record, and the sources the plan names, at the commit above, with a clean tree. It read the diff of the plan since round 19's commit, `.github/workflows/ci.yml`, `.github/workflows/cold-clone.yml`, `workspace.json`'s `direct_push` and `stop_gate` entries, `docs/procedure-endings.md`, `docs/extend-the-workspace.md`, `docs/decisions/0011-pages-go-straight-to-main.md`, `tests/hook_cases.py` and `tests/hooks/`, the hook parts under `parts/`, `wslib/runner.py`'s check and push code, and the test modules that read the repository's pages. It ran `gh run view 46104249965 --json jobs` for per-step CI times, timed `tests/test_kit.py` locally, and timed `hook_cases.py`'s cases locally, all of them and the three events the fast path keeps.

## Verdict

**Holds with fixes.** Round 19's fixes landed where they were aimed. The fast path sits in H2, after L3, and G0 merges at once. The classing trusts path patterns, not the log. The Q110 refusal reads the wrappers from the remote's tip. The guards, the harness, the budgets and the review loop are unchanged and still add up. Two things do not yet hold. Q110 is still not stated everywhere the old rule is: decision 0011 says pages go straight to main with two exceptions, and procedure endings' off-main rule makes the new push-table row unreachable (finding 1). And the `reads_pages` guard is a scan for page names in test code, so it misses the tests that read pages through a helper, the tutorial run among them (finding 2). Both are fixable inside H2.

## What survives

- **Round 19's moves hold.** The fast path sits in H2's gate pull request, after L3, and G0 no longer changes the workflow, so G0 merges at once. Criterion 64 sits with G2, whose re-check rewrites the README's Limits. Verified, by reading the diff since `b14da0c` against the G table and the G2 section.

So `kit/seed/README.md` and `.github/copilot-instructions.md` take the full run, and `evals/README.md` and `src/README.md` are excluded by folder. Verified, by `git ls-files '*.md'` against `workspace.json`'s `direct_push.machinery`.
- **The three hook parts named are the hook parts that read pages.** The other hook parts name a page only in their `PAGE` constant. `stop_gate` runs `ws.py check` over the pages, which the fast path's own `ws.py check --phase ci` step also does. Verified, by grepping each hook part under `parts/` for page reads.
- **The steps the fast path keeps are the cheap ones.** On every job, `grade.py --recorded`, the history scan, the commit checks and `ws.py check --phase ci` each took 7 seconds or less. That check runs every commit-and-ci check over the whole tree, so the checks that read pages run on the fast path.
