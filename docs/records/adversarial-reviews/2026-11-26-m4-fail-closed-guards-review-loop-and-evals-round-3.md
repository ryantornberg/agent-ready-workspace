# Red team review: docs/plans/m4-fail-closed-guards-review-loop-and-evals.md

A third fresh red team's attack on M4's draft hand-off plan, checking the claims its decisions rest on against the repository.

**In short:** holds with fixes, 12 findings. A force-push route outside the plan's numbered rows passes today, G2's standard-input rule as written refuses most everyday lines, and the routing suite can block slice Z.

The red team read the plan, both earlier records and the sources the plan names at the commit above. It ran the before-shell hook on crafted command lines, called the parser's `analyze` directly, ran both V8 commands, and counted command shapes in the stored eval transcripts and in this project's Claude Code session logs on the maintainer's machine. It ran no agent, no eval or selection run, and no command a guard judges. Hook probes passed a JSON payload to `python3 ws.py hook before-shell --tool claude-code` and read the exit code; nothing was executed.

## Verdict

**Holds with fixes.** The core still holds: one literal-word rule in the parser, grading files out of the recording's hash, a review loop with a mark and a gate, and staged eval budgets. Findings 1 to 4 must be fixed before approval. A route that force-pushes or deletes main passes every guard today, is not among F1 to F18, and is a literal-word misread that the one rule does not reach. G2's standard-input bullet, read as written, makes every pipe into `head` or `tail` unresolved, and choosing how to narrow it is a design decision the builder should not make alone. The routing suite has no way to pass the gate if any routing case misses, so slice Z's contract and index edits can fail CI with no fallback. And G3 leaves a config route through `git clone --config` and a `cd` into the clone. The rest can be settled without blocking.

## What survives

- **Every other runner holds.** The option-scanning fault is `watch`'s alone: 22 runners, with `--force` or `--delete` placed after `git`, are refused. So are `command`, `exec`, `builtin eval`, `env -S`, `find -exec` and `xargs` before a push. Verified, by running the hook.
- **The interpreter list opens no new route.** `awk 'BEGIN{system(...)}'`, `perl -e`, `python3 -c` with `os.system` and GNU sed's `e` flag all pass today. Exempting their code from shell parsing, as G2 plans, changes nothing for them. Verified, by running the hook.
- **H0a's split matches the code.** `wslib/shell.py` imports nothing from the engine, `parts/no_stage_all.py` imports only `wslib.shell`, and `covered_files` adds a graded hook and the parser only for `hook_allows` graders. So G3 and G4, which change parts no grader runs, re-grade trivially. Verified, by reading `parts/eval_record.py`'s `covered_files` and `HARNESS`, and the imports.
- **G0 and G1 touch no hashed file.** The hash covers the case, its page, `run.py`, `grade.py`, `proofkeys.py`, the arms, the hidden test, graded hooks, the parser and the scaffold. Not the manifest, the pre-push code or the merge helper. Verified, by reading `covered_files`.
- **Slice Z's contract and index edits do not stale H3's pages.** Debugging's guided arm reads a contract copy, `evals/proof/debugging/contract.md`, not `AGENTS.md`. Verified, in `evals/cases/debug-leak-check.json`. Inferred for the nine new pages, which follow M3's slice B7.
- **`proven-by` can name a slice report** as a bare path, a form `evals/proofkeys.py` already strips, so H3 needs no change to a frozen file. Verified, by reading its `LIST` pattern.
- **The always-loaded ceiling has room.** `AGENTS.md` and `CLAUDE.md` hold 4,740 of 6,000 bytes. Verified, `wc -c`; the other two pointer files were not measured.
- **The stored eval corpus is clean for G2's quoted-argument rule.** None of its 1,539 command lines holds a quoted argument of an unlisted program that the rule would newly refuse. Verified, by the same approximation as finding 5.
- **The review-session table sums to 186, and the eval-run table to 1,085 and 1,220.** Verified.
