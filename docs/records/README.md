# Records

What this folder holds: records of work that happened, kept as evidence. For anyone checking what a review or a run found.

**In short:** one folder per record type. Instruction reviews go in [instruction-reviews/](instruction-reviews/README.md), with their index. Adversarial reviews go in `adversarial-reviews/`, one dated file per review, as [adversarial review](../playbooks/adversarial-review.md) says. More record types arrive with M3's sub-batch B.
