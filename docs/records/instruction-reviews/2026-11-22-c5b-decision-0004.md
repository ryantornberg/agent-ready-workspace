# Instruction review: docs/decisions/0004-the-hook-contract.md

**In short:** 6 findings: 5 contradiction, 1 enforcement. | 1 | contradiction | "What a part may read", the `"ci"` bullet, against `wslib/ci.py` (`summary`) | "It gives how many finished runs in a row failed, when the first of them started" does not hold when a passed-over run is among the 20 read. `summary` sets `at_least` only when the streak fills every run it kept and those number 20, so a cancelled or pull-request run among the 20 makes a streak that may run further back read as exact, and `since` gives the start of the oldest failure read, not the first. | 2 | contradiction | "Where the engine does the rest", the `gh` bullet, against `wslib/merge.py` (`repository`) | "An `origin` that names no GitHub repository gets no call" holds only for a local path. `merge.repository` refuses a local URL or one with no owner and name, and passes any host, so an origin on another host gets a `gh` call. | 3 | contradiction | "Where the engine does the rest", the **Git** bullet and the `gh` bullet; "What it gave up", its first bullet | "**Git** runs in `wslib/gitcall.py`" gets an exception it does not label: the origin read runs `git config --local` through `wslib/merge.py`'s own `subprocess.run`, with a limit of 10 seconds, outside `gitcall` and outside the 3-second deadline.
