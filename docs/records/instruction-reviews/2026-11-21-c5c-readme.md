# Instruction review: README.md

This records the instruction review of slice C5c's README change, for its author and for readers of the git folder and shell guards' promises.

**In short:** 7 findings: 5 enforcement, 1 contradiction, 1 step. The new row promises that no git config key deciding what a git command runs or where a push goes changes, but `git config core.hooksPath /dev/null` and `git remote set-url` both pass. A variable set from another variable, an unread include and the system config file all get past the shell guard, and the Limits bullet names none of them.
