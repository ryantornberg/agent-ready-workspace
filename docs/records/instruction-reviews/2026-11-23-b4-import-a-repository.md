# Instruction review: docs/playbooks/import-a-repository.md

This records the instruction review of slice B4's new devops lane playbook for importing a code repository. It is for the page's author.

**In short:** 7 findings: 1 contradiction, 5 step, 1 enforcement; 2 blocking. Step 3 always works in a worktree branched from the main copy's HEAD, against the contract's "only then" and the workspace's own advice to branch from `origin/main`. The hub and unit docs are guidance pages, but no step runs their instruction review, so the commits of steps 7 and 8 are refused.

What a fix broke:

- Blocking. Steps, step 3: the default `git fetch origin` then `git switch --no-track -c import/REPO origin/main` runs in the main working copy before any lease check. The lease is taken only on the first edit to a tracked file, which comes at step 7. No hook refuses a plain switch: `no_discard` refuses only `switch -f`, and its cases include "switching branch without --force passes". So with another live session in the main copy, the switch swaps that session's branch under it. Decision 0005 names "a branch switch swapping every session's files" as one of the costs the lease exists to stop, and bug grooming's step 3 forbids checking out another commit in the main working copy because "another session may be working there". That session's later page commits then land on `import/REPO` and ride into the import's pull request. In a throwaway repository, the switch also failed, exit 1, with "Your local changes ... would be overwritten by checkout", when an uncommitted change touched a file that local, unpushed commits on main had changed. Step 3 gives no route for that failure, and "leave them" rules out a stash. No step switches the main copy back to `main` either, so it stays on the import's branch after step 12. Verified: the throwaway run, `parts/lease.py`'s docstring, the `no_discard` case, decision 0005's context and the bug grooming text. Inferred: that a second live session is in the main copy when an import starts. A fix that closes all three: always make the import's worktree from `origin/main`, labelled as an exception to the contract's "Only then", since an import's branch must not move the shared copy; or check first that no other live session holds the lease, and switch back to `main` at step 12.
