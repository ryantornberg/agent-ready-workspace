# Instruction review: docs/parts.md

This records the review of C8's edits to the parts page: the kit's section, the cold-clone sentence and two part rows, for their author.

**In short:** 4 findings: 1 contradiction, 1 step, 1 trigger, 1 placement, none blocking. Keeping a file does not exempt it from every check: a kept proven page fails `proof` and `eval_record`. Adopt silently leaves out files git does not track yet, so the instance's checks and the kit's own test fail before a new file is added. The page is synced, so instances get sentences about the kit's tests and cold-clone job, which they lack. The index gives no route to the kit.
