### Dispositions (fix round 1)

- 1, control-character escapes: fixed. An escape that makes a tab, a new line or the other ASCII white-space characters is refused, and so is `\cX`, read as the control character it makes. A colour code and a letter outside ASCII, such as `$'✓'`, pass. Cases for `\x0a` and `\cJ` in `eval`'s text.
- 2, runners in the data list: fixed. `npm`, `pnpm`, `yarn` and `brew` leave the data list and join the runners, and `sed` and `awk` leave the data list, since each can run a command. A case for `npm exec -c`.
- 3, a runner not on the list, with a substitution: fixed. `taskpolicy` and a few more join the runners. For any program the parser does not read, a substitution that runs a program the guards judge, or looks one up with `command`, `which`, `type` or `whence`, is refused. A case for `taskpolicy -b $(command -v git)`.
- 4, runner text with no spaces: fixed. Text that holds `$` is read as a command line too, and a program word that holds `$` is judged by its name up to the first character no name holds, so `git${IFS}push` reads as `git`. The code an interpreter such as `python3 -c` is given is not read as a command line; the README's limits name interpreters. A case for the `flock -c` line.
- 5, a wrapper's own words set by a loop, `IFS`, `set --` or `read`: fixed by refusing any unquoted variable or substitution among a wrapper's or a shell's own words; the refusal says to quote it. Cases for the `for` loop and the `IFS` line.
- 6, arithmetic with quoted or one-word commands: fixed. Any substitution inside a `((`, and a quote before or after a space, is refused. Cases for the quoted `git` and for `$(( $(cat .env) ))` in `secrets_shell`.
- 7, the README's `arch "$CMD"` example: fixed; the paragraph now says a runner missing from the list, given a variable the line does not set, gets past them.
- 8, `fnmatch`: fixed in code. The block no longer imports `fnmatch`; it matches a glob with `re`, which decision 0004 allows, so the exceptions table is unchanged and `AccessContractTests` passes.
- 9, a variable's text evaluated as arithmetic: left for M4, as the finding says; the parser reads the line correctly.
- 10, refusals beyond the pages: fixed in part. Braces in a word of an unread program are refused only when one of the words they make may name a judged program, so `pytest tests/test_{a,b}.py` passes. `pgrep`, `pkill`, `ps` and `kill` join the data list. A check mark escape passes. The depth rule names only a wrapper, shell, `eval`, `watch` or `find` past the depth, so `echo hi` inside 8 nested `sh -c` passes. `pytest -k env`, `docker exec app bash` and a substitution in arithmetic stay refused, and the README says so for the last. Of the 1,523 stored commands under `evals/runs/*/`, none is refused (verified).
