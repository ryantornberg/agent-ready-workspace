# Instruction review: README.md

This records the review of C8's README edits on the kit, `ws.py adopt`, drift and upgrade, for their author and their readers.

**In short:** 4 findings: 3 contradiction, 1 placement, none blocking. The new paragraph says an upgrade "replaces the rest", but it refuses outright while any synced file is edited. The steps under it, and the paragraph after them, still describe a copy made by hand, and they now exist twice, here and in the seed README, already worded differently. The cold-clone row's trigger list leaves out `tools/setup_steps.py`.

The whole page was read, with `git diff README.md` for the change.
