# Instruction review: docs/extend-the-workspace.md

This records the review of B2t's edit to extend the workspace's steps 6 to 8, for its author and its readers.

**In short:** 7 findings: 3 contradiction, 2 step, 1 enforcement, 1 placement; 1 blocking. Step 8's exception to procedure endings' push table names no one to push, so in a team's workspace an agent pushes a branch that a person should push. The rest are an unlabelled commit exception, a false "not your files", a summary that drops the log row's commit, a self-referring sentence, an unenforced "never to main" and two stale rules rows.
