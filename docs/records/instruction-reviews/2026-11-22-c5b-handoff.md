# Instruction review: docs/playbooks/handoff.md

This records the review of slice C5b's change to the handoff playbook, for its author and for agents that stop or resume mid-task.

**In short:** 3 findings: 1 step, 1 trigger, 1 enforcement. Clearing a marker names no folder to run in, and run from the wrong working copy it reports success-shaped output while the marker stays. The notice tells every session that starts in the working copy to resume, whatever the person asked. "Only the engine writes it" overstates what the guards refuse.
