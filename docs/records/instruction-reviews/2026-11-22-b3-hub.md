# Instruction review: docs/templates/hub.md

This records the instruction review of the new project hub template, for its author and for agents writing or keeping a project's hub.

**In short:** 4 findings, none blocking: 1 trigger, 1 step, 1 contradiction, 1 enforcement. The templates index routes to the hub per repository while the page makes it per project; a copy has no default folder in the workspace; the worked example falls short of the reader standard; and the rules row names a planned check for the wrong rule.

In scope: the whole page, as a new template.
