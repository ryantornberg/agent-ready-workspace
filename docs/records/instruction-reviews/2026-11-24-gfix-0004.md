# Instruction review: docs/decisions/0004-the-hook-contract.md (slice GFIX)

This records a fresh session's narrow re-check of slice GFIX's code and its edit to decision 0004, for the slice's builder and the maintainer.

**In short:** 7 findings: 4 enforcement, 3 contradiction; 2 are blocking. A NUL escape at the start of a word, such as `$'\0'git push --force origin main`, passes all seven shell guards, and bash runs git. A wrapper named in another letter case, such as `NICE -n 5 git push -f origin main`, passes all seven, and both shells run git. The ANSI-C, arithmetic, wrapper-word, depth and case routes hold in their direct variants otherwise, and no fixed program list is left. Of the 1,539 stored commands, 9 are newly refused, all `type git` or `which -a git` in one eval case.

## Checked with no finding

- enforcement, ANSI-C: refused by all seven guards (verified): `$'\x67it'`, `$'\147it'`, `$'git'` (zsh ran git), `$'\U00000067it'`, `g$'\x69't`, `git $'\x70ush'`, `git push $'\x2d\x2dforce'`, `$'-\x66'`, `+main` built with `\x2b`, `\053` or `\53`, `$'git\x09push ...'`, `eval $'git\x20push ...'`, `eval $'true\x3bgit push ...'`, the new-line forms `\x0a`, `\012`, bash's `\cJ`, `\cj` and zsh's `\C-j`, and the same in `sh -c` and `bash -c` text. The named escapes `\n` and `\t` are read by the parser itself (verified). `\x0b`, `\x0c`, `\x0d` and `\x1b` pass, and neither shell splits on them (verified). `$'\0147it'` and `$'\\x67it'` pass, and neither shell runs git (verified).
- enforcement, NUL after text: `git$'\0'`, `git$'\x00'`, `git$'\000'`, `main$'\0'`, `$'main\0x'`, `\u0000`, `\U00000000`, `\c@`, `\C-@`, `--$'\0'admin` and `$'--force\0nope'` are refused by all seven (verified). The rule does not name `FOO=$'\0' git push`, which is harmless (verified).
- enforcement, arithmetic: `((git push -f origin main) )`, `((git push -f origin main))`, `(( $(...) ))`, `$(( $(...) ))`, the backtick form, `((git${IFS}push...) )`, `((git;git push ...) )`, a `for ((` header holding a substitution, `(( a[$(...)] ))` and `((x=1)) && ((git push ...) )` are refused by all seven (verified). `$((1+2))` and `for ((i=0; i<3; i++))` pass (verified).
- enforcement, a wrapper's or shell's own words: braces after `nice -n`, `nice -n{...}`, `timeout`, `env`, `env -u`, `stdbuf -o`, `sudo -u`, `exec` and `time`; `nice -n $N`; globs `*`, `?` and `[g]it`; `sh {-c,git}`, `bash -{c,}` and `bash $FLAGS` are refused by all seven (verified). `command -v $p` and `command -v {git,} push` pass, and neither shell runs git for the second (verified).
- enforcement, depth: 5 to 12 nested `sh -c`, `bash -c`, `eval`, `env sh -c` and a mix of `sh -c` and `eval`, around `git push -f origin main`, `gh pr merge 5 --admin`, `printenv`, `nice git push ...` and `GIT push ...`.
