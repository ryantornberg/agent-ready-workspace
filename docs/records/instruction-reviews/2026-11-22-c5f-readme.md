# Instruction review: README.md

This records the review of C5f's README edits on the secrets guard and `ws.py with-secrets`, for its author and its readers.

**In short:** 2 findings: 1 contradiction, 1 enforcement. Under Codex's `agent-ready` profile, which the README tells a person how to turn on, `with-secrets` cannot read the secrets file in the main working copy and exits 2, yet the row offers it as the route in both tools.
