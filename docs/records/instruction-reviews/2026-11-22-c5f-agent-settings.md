# Instruction review: docs/agent-settings.md

This records the review of C5f's edits to the agent settings page, on the secrets guard and `ws.py with-secrets`, for its author and its readers.

**In short:** 5 findings: 3 contradiction, 1 enforcement, 1 trigger. Under the page's own Codex profile, `with-secrets` cannot read the secrets file in the main working copy and exits 2. The page tells an agent to `echo "$NAME"` while the hook's message says to ask the person, and its Limits list the same echo as a miss. `ps eww` and interpreters dump the environment past the hook, and `ps eww` shows a `with-secrets` child's values. `$NAME` on the command line is filled in by the calling shell, not left empty. `INDEX.md` routes no topic to this page.

## Scope

In scope: every change, which is the In short line, the Claude Code cell of the table in "The secrets files", the new section "Secrets in the shell", the four new bullets in "## Limits" and the two new rows in "## Rules". The whole page was read. Read beside it: `AGENTS.md`, `INDEX.md`, `docs/procedure-endings.md`, `docs/layout.md` (page kinds), decision 0004 with its uncommitted change, `docs/parts.md` with its uncommitted row, the README with its uncommitted change, `workspace.json`, `.codex/config.toml`, `.codex/hooks.json`, `.claude/settings.json`, `parts/secrets_shell.py` and its cases, `wslib/secrets.py`, `wslib/runner.py` (`command_with_secrets`), `tests/test_secrets.py`, `tests/hooks/before-shell.json`, and in the M3 plan the C5 row of sub-batch C, the C5f row of the split, criterion 40 and the queue for slice Z. `secrets_shell.decide` was called with the manifest's entry on about sixty command lines, and the whole before-shell chain, `python3 ws.py hook before-shell --tool claude-code`, on five. `ws.py with-secrets` was run for real against a throwaway repository under a temporary folder of my own, holding a `.env` with one made-up value: plain, with arguments that name the variable, beside `ps eww`, and under `codex sandbox` (codex-cli 0.169.0) with the `agent-ready` profile given on the command line. `python3 ws.py selftest` passes (`secrets_shell` 115 of 115), `python3 -m unittest tests.test_secrets -b` runs 12 tests OK, and `python3 ws.py check` exits 0 (verified).
