# Instruction review: docs/decisions/0018-unattended-runs-write-only-to-a-branch.md

This records the instruction review of B5's new decision record 0018, on what an unattended run may write, for its author and its readers.

**In short:** 3 findings, 2 blocking: 3 contradiction. The run is told to move the workspace's pin to a commit only its own branch holds, which `pin_on_default` refuses, and that pin move is a write the record's first rule forbids. The **In short** line counts three rules where the Decision gives four.
