# Instruction review: kit/seed/README.md

This records the review of the seed README that `ws.py adopt` writes as a new instance's `README.md`, for its author and its readers.

**In short:** 8 findings: 5 step, 3 contradiction; 5 blocking. An instance cannot make its first commit, or commit an upgrade, because `review_trailer` refuses both. Keeping your own copy of the proven playbook fails the checks. An agent running the setup is refused at `core.hooksPath`. Step 1 changes a contract whose own rules table still demands an eval run that a new instance cannot make.

In scope: the whole page, read as an instance's `README.md`, with links read from the instance's top folder. The page was read as committed into a scratch instance, where `<!-- kit: proof table -->` is replaced by a table of 35 rows.

Read beside it: the instance's `AGENTS.md`, `INDEX.md`, `evals/README.md`, `kit.lock.json`, `workspace.json`, `evals/arms.json`, `.githooks/`; in the worktree, `README.md` (its "Use it for your own team", to compare), `docs/adopt-the-workspace.md`, `docs/decisions/0007-the-kit.md`, `docs/decisions/0006-what-proven-means.md`, `docs/changing-the-machinery.md`, `docs/playbooks/instruction-review.md`, `kit/kit.json`, `kit/seed/ci.yml`, `wslib/kit.py`, `wslib/kitlock.py`, `parts/kit_drift.py`, `parts/proof.py`, `parts/eval_record.py`, `tests/test_kit.py`, `.github/workflows/cold-clone.yml`, and the plan's C8 row, criterion 47 and the entry "The kit's merge setting moves to C8".
