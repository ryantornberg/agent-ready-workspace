# Instruction reviews

The index of instruction-review records: each record, the page it covers and the classes of defect it found. For reviewers, and for whoever counts a stop rule.

**In short:** one row per record. The [instruction review](../../playbooks/instruction-review.md) says how a record is written and when a commit must name one. The `review_index` check holds each row to its record, and requires one for each page on its `required` list: the guidance M3's plan names from before the review existed.

A class is counted from a record's findings, leaving out a finding the author declined. "none" means the review found nothing, or declined all it found.
