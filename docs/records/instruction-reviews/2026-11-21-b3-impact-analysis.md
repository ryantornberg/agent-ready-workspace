# Instruction review: docs/playbooks/impact-analysis.md

This records the instruction review of the new impact analysis playbook, for its author and for agents who map what a change reaches.

**In short:** 5 findings: 1 contradiction, 4 step. The page and the review orchestrator disagree on which steps the docs drift reviewer runs. Step 1 cannot take a pull request or a given range, step 2 matches chains by path alone, step 3 searches only `src/`, and step 7's yes branch never ends.
