# Instruction review: docs/decisions/0019-every-fix-lands-on-trunk-first.md

This records the instruction review of B5's new proposed decision record 0019, a trunk-first branching convention, for its author and its readers.

**In short:** 2 findings, none blocking: 1 step, 1 contradiction. In an instance the record is a synced file, so the DevOps owner's accept or reject is a hand edit the `kit_drift` check refuses until the file is kept; and the rollout list misses the existing pull request template and git-host operations' title-or-description rule.

## Scope

In scope: the whole page, which is new. Read beside it: `AGENTS.md`, `INDEX.md`, decision 0007 ("Decision", "Drift"), `kit/kit.json`, `parts/kit_drift.py`, `docs/templates/decision-record.md` ("How a record changes"), `docs/templates/pull-request.md`, `docs/playbooks/git-host-operations.md` ("The operations"), `docs/reading-paths.md` ("DevOps"), `docs/layout.md`, `docs/authoring.md` and `docs/procedure-endings.md`.

Runs (verified): `python3 ws.py check` in the worktree prints one `eval_record` warning and no failure, so the `decisions` check accepts the proposed record's `date` and `deciders`.

## Findings

| # | Class | Where | Finding | Disposition |

| 1 | step | The **In short** line, "Each instance's DevOps owner decides"; "Decision", its opening line | Not blocking. The record exists here to be accepted or rejected in an instance.
