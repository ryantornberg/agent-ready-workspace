# Instruction review: docs/adopt-the-workspace.md

This records the instruction review of the new how-to "Adopt the workspace", for its author and for anyone settling its findings.

**In short:** 7 findings: 2 contradiction, 3 step, 1 trigger, 1 enforcement. The transfer tables, the kit's planned state and the done table mostly hold. The page disagrees with the README it defers to, routes machinery edits through the doc path, and leaves this workspace's milestone state in an instance.

## Scope

The whole page, which is new. Read beside it: `AGENTS.md`, `CLAUDE.md`, `INDEX.md`, `docs/definition-of-done.md`, `docs/orchestration.md`, `docs/layout.md`, `docs/glossary.md`, and every page it links: `README.md` ("Try it", "Use it for your own team"), `docs/changing-the-machinery.md` (its machinery table, its path and its traps), `docs/parts.md#baselines`, `docs/commits.md`, `docs/layout.md`, `docs/extend-the-workspace.md`, `docs/question-log.md`, `docs/playbooks/tracker-operations.md`, `docs/playbooks/git-host-operations.md`, `docs/machine-self-check.md`, `docs/size-the-work.md`, `docs/templates/hand-off-plan.md`, `docs/playbooks/instruction-review.md` and `docs/rules/`. Also the other pages of batch 4, in particular `docs/maintain-the-workspace.md`, for the interface sweep. Commands and files checked: `python3 ws.py check` (passes, one unrelated warning), `python3 ws.py rules`, `python3 ws.py pins`, `workspace.json` (its `building` list and the `direct_push` machinery list), `parts/deny_list.py`, `wslib/pins.py`, the front matter of `docs/plans/*.md`, and row C8 of the M3 plan for the kit.
