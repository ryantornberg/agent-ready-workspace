# Instruction review: the Q54 guard change in README.md and decision 0004

This records a fresh session's narrow re-check of the Q54 change, for its builder and the maintainer.

**In short:** 6 findings, 2 blocking: 5 enforcement, 1 contradiction. The blocking ones: a brace in the program word's folder part, such as `{/usr/bin,-C/tmp/x}/git push -f`, and zsh's extended glob `git#` still pass the guards.

## Scope

In scope: commit 778ee31, the README bullet "The shell guards refuse a program word the shell would expand", and the 0004 paragraph "Amended 2026-11-24, M3 slice Z, on the maintainer's answer to Q54", with the `secrets_shell` row of "The exceptions". Read beside them: README.md's Limits, the whole of 0004, the plan's Q54 entry and `wslib/gitrules.py`.

Run: `python3 ws.py selftest`; the three test groups the brief names; `git diff e92df6e HEAD` of the hashed files. Each guard's `decide` was called on events modelled on its `*.cases.json`, on this tree and on an export of origin/main at 84f7cc3. Real `bash` and `zsh` ran each shell form against a fake `git` that prints its arguments. No real push or reset ran.

## Dispositions after the re-check (fix round 1)

The builder's fix round, before a fresh re-check of it. The README bullet's share of these findings is recorded in [the README record](2026-11-24-z-readme.md).

- 1, blocking, the brace in the folder part: fixed. `gitrules.expanded_program` now takes the command and walks it as the parser does, through a subclass of the parser's walker that notes each program word whole before the parser keeps its last part. Each guard calls it once per command; `no_admin_merge` holds the same walk. New cases refuse `{/usr/bin,-C/tmp/x}/git push --force origin main`, the same `reset --hard` while the lease is held, the `-u origin HEAD` push and `{/usr/bin,-R/x}/gh pr merge 5 --admin` (verified, `python3 ws.py selftest`).
- 2, blocking, zsh's extended glob: fixed. The rule adds `#`, `^`, and `~` after the first letter, so `~/bin/tool` still passes. New cases refuse `git#`, `g^x`, `g~x` and `/usr/bin/env#`, under `with-secrets` too (verified, `python3 ws.py selftest`).
- 3, ANSI-C quoting: parked as Q74, with the unread runners of finding 6. It is outside Q54's scope and open on main.
- 4, "do so": fixed. The paragraph now says `push_lease` and `no_discard` refuse such a word only while another live session holds the lease.
- 5, bash's extglob grouping: fixed. Both pages name bash's `g@(i)t` beside zsh's `g(i)t`, left for M4.
- 6, unread runners: parked as Q74.
